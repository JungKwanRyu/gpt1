# Nintendo Switch 정식 이식 사전 점검

> 이후 사용자가 대상을 홈브루로 변경했다. 이 문서는 당시 정식 이식 조건을 기록한 이력이다. 현재 작업 상태는 [홈브루 리버싱 기록](HOMEBREW_REVERSE_ENGINEERING.ko.md)을 참고한다.

점검일: 2026-10-27
대상: 일반 Nintendo Switch에서 실행하는 정식 이식판
상태: 입력 자료 부족으로 이식 구현 및 기기 검증 미착수

## 실제 확인한 자료

- 게임 식별: DosBox/Settings.conf에 창세기전 3 파트 1 커스텀 버전으로 기록됨.
- Store/image.img: 1,791,885,312바이트, MBR 디스크 이미지, 오프셋 32,256바이트의 FAT16 파티션.
- 7-Zip으로 내부 디렉터리 목록을 읽을 수 있음. 게임 실행 파일이나 원본 데이터는 변경하지 않음.
- 실행 파일: G3P1/G3Launch.exe, G3P1/JobEdit.exe, G3P1/SaveEdit.exe.
- DLL: G3P1/MFC42D.DLL, G3P1/MSVCRTD.DLL, G3P1/alpha.dll.
- 데이터: G3P1/BGMs, BGRs, Btls, Snd 등의 자산과 G3Data/*.txt 설정 자료.
- Store/DG_9xOpt의 실행 설정은 D:/G3Launch.lnk 등 Windows 바로가기를 지정함.
- DosBox의 기존 설정은 W98KR_Daum_Final 실행기와 Pentium 에뮬레이션을 지정함.
- 작업 폴더 및 이미지 내부 목록에서 C/C++/C# 소스, Visual Studio 프로젝트, CMakeLists.txt, Makefile 또는 Unity/Godot/Unreal 프로젝트를 찾지 못함.

이미지 목록 기반 점검이며 실행 파일의 역분석이나 게임 실행 테스트는 수행하지 않았다. 이 자료에서 발견되지 않았다는 의미이며, 다른 위치에 있는 소스의 존재 여부까지 판단한 것은 아니다.

## 현재 가능한 결론

현재 자료는 Windows 실행 파일과 게임 자산이다. Nintendo Switch용 빌드 입력으로 사용할 게임 소스와 프로젝트가 확인되지 않아, 실행 파일 이름 변경이나 DOSBox 설정 변경으로 정식 이식판을 만들 수 없다. 홈브루용 패키지는 사용자가 선택한 대상이 아니므로 만들지 않았다.

## 다음 작업에 필요한 자료

1. 게임 및 엔진의 소스 코드와 원래 빌드 프로젝트, 사용한 라이브러리와 빌드 방법.
2. 승인된 Nintendo Switch 개발 환경의 사용 가능 여부. SDK 및 접근 제한 자료는 공개 저장소에 넣지 않고 승인된 로컬 환경에서 사용한다.
3. 게임과 포함 자산을 수정하고 정식 배포할 권한 및 사용할 수 있는 미들웨어 라이선스의 확인.

Nintendo 공식 등록 안내: https://developer.nintendo.com/register
개발자 등록 후 Switch 접근 권한을 별도로 신청하는 절차가 안내되어 있다.

## 자료 확보 후 구현 순서

1. 원래 PC 프로젝트를 빌드하고 시작, 전투, 저장 및 불러오기 동작을 기준으로 기록한다.
2. 소스의 Windows 의존 부분을 확인하고 화면, 입력, 오디오, 파일 시스템, 시간 처리의 이식 범위를 결정한다. DLL 이름만으로 실제 게임의 API 사용 범위를 확정하지 않는다.
3. 승인된 SDK와 지원 툴체인으로 Switch 빌드 대상을 추가한다.
4. Joy-Con 및 Pro 컨트롤러 조작, 글자 가독성, 저장 처리, 휴대 및 독 모드와 중단/복귀 동작을 구현한다.
5. 개발 기기에서 시작, 주요 전투, 동영상/음성, 저장/불러오기와 장시간 실행을 검증한다.
6. 성능과 메모리 문제를 해결하고 접근 가능한 공식 요구사항에 따라 제출 빌드를 검증한다.

## 완료 판정

현재 산출물은 사전 점검 문서뿐이다. Switch 실행 바이너리, 설치 패키지, SDK 빌드 성공, 실제 기기 구동 및 성능을 확보하거나 검증한 상태가 아니다.
