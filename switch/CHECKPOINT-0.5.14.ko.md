# 0.5.14 오디오 믹서·화면 초기화 개선

- 음성별 PCM 보간·볼륨·팬 계산을 네이티브 코드로 옮깁니다. 오디오 장치 출력 주파수, 재생 시계, 음성 종료·반복 및 믹서 잠금 정책은 유지합니다.
- 지원 범위를 벗어나는 입력은 원래 게임의 계산으로 처리합니다.
- 일반 화면의 보이는 영역을 지우는 반복 작업도 네이티브 코드로 처리합니다. 원래 관리 코드 경로는 남겨 둡니다.
- 실제 PC 게임 1.0.86의 원래 믹서와 PCM 출력·재생 위치·반복 횟수·종료 결과를 비교하는 회귀 검증을 추가합니다.
- 이전 버전의 영상 합성·필드·효과·스프라이트 수정은 유지합니다.

ZIP 전체 내용을 SD 카드 루트에 덮어씁니다. 기존 게임 데이터, 저장 파일 및 launcher.ini는 유지합니다. 패치 코드가 변경돼 첫 실행에는 DLL 패치 캐시를 다시 만듭니다. 완성된 원본 자료 캐시는 조건에 맞으면 재사용합니다.

실기 성능 개선 폭은 적용 후 확인이 필요합니다. probe.log의 AUDIO supply와 performance.log를 함께 비교해야 하며, 표시 FPS만으로 영상 디코딩·오디오 지연이 모두 해결됐다고 판단하지 않습니다.
