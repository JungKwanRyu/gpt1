# 0.5.16 음성 동기화·Moses 화면 개선

- Bink 음성의 역변환 계산을 네이티브로 처리합니다. 영상 음성과 대사 음성에 공통 적용되며 원래 계산 경로를 보존합니다.
- 영상 선행 PCM은 1초를 준비합니다. 미기록 PCM을 읽지 않는 보호와 재공급 시 원본 위치 유지는 계속 적용합니다.
- 대사 글자 진행을 믹서가 만든 블록과 출력 장치가 재생한 PCM 위치에 맞춥니다. 음성이 준비되지 않은 동안 글자가 먼저 진행하던 동작은 변경했습니다. 창을 열 때 음성을 먼저 준비하고, 같은 대사의 중복 준비 요청은 합칩니다. 음성이 없거나 출력 장치가 없는 경우는 기존 시간 진행을 사용합니다.
- Moses 화면에서도 중복 대화창 그리기를 생략합니다. 배경 복사, 전체 화면 크로스페이드·검정·파랑 전환을 네이티브로 처리합니다. 전환은 프레임 개수 대신 30틱/초 기준의 경과 시간으로 진행합니다. 1초 넘는 공백은 전환 따라잡기에서 제외합니다.
- 대화창 배율·얼굴 그림을 네이티브로 처리합니다. 반투명 전역 얼굴 효과는 기존 계산으로 처리합니다.
- 필드의 임시 레이어 목록과 용량을 재사용합니다. 표시 대상과 정렬 순서는 매번 확인해 동적인 변화를 유지합니다.
- 자료 캐시 미사용 이유를 기록합니다. 타임스탬프만 달라졌다면 모든 실린 입력의 동일성을 확인한 뒤 캐시 표시를 갱신합니다. 누락·내용 변경은 기존 복구로 처리합니다.
- 일반 성능 로그는 묶어 쓰며 오류·단계·종료 기록은 즉시 저장합니다.

ZIP 전체를 SD 루트에 덮어써 NRO와 managed 폴더를 함께 갱신하세요. 기존 게임 데이터·저장 파일·launcher.ini는 유지하세요. 첫 실행에는 패치 캐시를 다시 생성합니다. PC의 prepare-sd.cmd는 선택 사항입니다.

실기 성능과 음성·글자 동기화는 같은 구간에서 확인해야 합니다. 큰 장면의 최초 자료 읽기와 첫 셰이더·글꼴 준비 시간이 모두 제거된 것은 아닙니다.
